## Changes

### 1. Restore v1.9.5 Recognition Request

**What**: Remove both `EXTRA_SPEECH_INPUT_COMPLETE_SILENCE_LENGTH_MILLIS` and `EXTRA_SPEECH_INPUT_POSSIBLY_COMPLETE_SILENCE_LENGTH_MILLIS` extras added in v1.9.6.

**Preserve**: SimpleDateFormat reuse (main-thread only, safe optimization)

### 2. Add Voice Progress Indicator

**What**: Small circular progress indicator visible during voice dictation session.

**Style**: Match existing AI progress indicator
- `ProgressBar(context, null, android.R.attr.progressBarStyleSmall)`
- Accent color tint: `prefs.accentColor`
- Indeterminate spinner

**Placement**: Search field trailing edge, non-overlapping, 8dp margin

**Lifetime** (user approved): "Until listening stops"
- Show: When `startVoiceDictation()` succeeds
- Keep: Through `onReadyForSpeech`, `onBeginningOfSpeech`, all `onPartialResults`
- Hide: On `onEndOfSpeech`, `onResults`, `onError`, `cancelListening`, manual edit, dismiss, navigation
- Late final results after `onEndOfSpeech` still populate correctly

**Not**: Visual label, overlap with text, query width changes, disabled typing
